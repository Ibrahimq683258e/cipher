Frequently Asked Questions

Are generated passwords sent to any server?

No. Passwords are created entirely in your browser memory using Web Crypto random generator APIs (`window.crypto.getRandomValues`). No network requests are made.

What makes a password cryptographically secure?

A cryptographically secure password uses random numbers generated from hardware entropy rather than predictable pseudo-random algorithms like `Math.random()`, ensuring maximum resistance against cracking.

Why should I exclude ambiguous characters?

Excluding ambiguous characters like `1`, `l`, `I`, `0`, and `O` prevents confusion when manually typing or reading passwords across different fonts and screens.

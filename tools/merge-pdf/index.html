Frequently Asked Questions

Are my PDF documents uploaded to a server?

No. PDF document processing and merging uses `pdf-lib.js` directly in your web browser. No document data is sent over the network.

Is there a file size limit for merging PDFs?

Because processing relies on your device's RAM and CPU, you can merge documents of any size as long as your browser memory permits.

Will my PDF page quality or vector formatting be degraded?

No. PDF page contents, vector fonts, and layout structures are copied page-by-page into the new container document without rasterizing or losing clarity.

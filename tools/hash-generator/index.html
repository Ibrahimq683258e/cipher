Frequently Asked Questions

What is a cryptographic hash function?

A hash function takes an arbitrary input string or binary file and maps it to a fixed-size string of bytes. It is a one-way mathematical function used to verify data integrity.

Are my files uploaded when generating hashes?

No. File buffer processing occurs 100% inside your browser using the native Web Crypto API and local client JavaScript libraries.

Which hash algorithm should I use for security?

SHA-256 and SHA-512 are recommended for modern security standards. MD5 and SHA-1 are included for checksum integrity verification of legacy software files.

About Cipher

Browser-Based Tools with Local File Processing

Our Privacy Engineering Mission

Cipher was built on a fundamental principle: online security and file manipulation tools should not require users to surrender their privacy or upload sensitive documents to unknown third-party cloud servers.

Traditional online file tools upload user data to remote web servers for conversion, processing, or encryption. This introduces significant risks of data breaches, accidental retention, or unauthorized surveillance.

Cipher uses modern web browser standards, including the Web Crypto API (`window.crypto`), HTML5 Canvas, WebAssembly, and local Blob streams to process tool inputs in your browser. The website may also load third-party services, including advertising, which can collect browser or device information as described in our Privacy Policy.

Key Pillars of Cipher

  • Local Tool Processing: Files, passwords, and cryptographic keys are processed in your browser and are not sent to Cipher for tool processing.
  • Clear Data Practices: Our Privacy Policy explains third-party services, contact form data, advertising, and optional analytics.
  • High Standards of Cryptography: AES-256-GCM authenticated encryption combined with PBKDF2 key derivation (250,000 iterations).

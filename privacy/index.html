Privacy Policy

Last updated: September 2025

1. Zero File & Payload Data Collection

Cipher operates entirely in your web browser. When you use our Password Generator, Hash Generator, Base64 Converter, QR Code Generator, Image Compressor, PDF Merger, or File Encryptor, your files, passwords, text entries, and generated outputs stay exclusively in your device's memory.

2. Local Storage & Cookies

Cipher uses browser `localStorage` solely to store user UI preferences (such as your preferred dark or light color theme). No personal identifiers or trackable analytics cookies are set by Cipher.

3. Third-Party Resources & Advertising

Cipher loads static web fonts via CDN. The Contact page is designed to use Cloudflare Turnstile and a configured Apps Script service for message delivery. Third-party advertising vendors (such as Google AdSense) may serve contextual advertisements on our pages. These advertising networks may collect standard browser metadata (such as IP addresses and device user-agent strings) to serve relevant ads according to their respective privacy policies.

4. Service Worker Caching

Our Progressive Web App (PWA) service worker caches only static HTML, CSS, JavaScript, and image assets required to run the application shell offline. User files and results are never written to the service worker cache.
